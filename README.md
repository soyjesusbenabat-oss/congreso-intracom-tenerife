# congresointracom.com

Web del VI Congreso Internacional Intracom (Universidad de La Laguna, 2 a 4 de diciembre de 2026).

Sitio estático de una sola página, diseñado en Claude Design. `index.html` lleva el diseño y los
textos; `assets/` guarda las fotos del comité y las imágenes, traídas del WordPress anterior para
no depender de él.

Los botones de inscripción llevan al área privada del congreso en
`conferences.portalintracom.com`, y los enlaces legales, a las páginas legales de esa plataforma.
